# Publicación y dirección de Listen to Earth

Actualizado: 15 de noviembre de 2026 (República Dominicana).

## Estado público vigente

- Sitio: https://dalgenisdalgenis-hue.github.io/listen-to-earth/
- Fuente de GitHub Pages: rama `main`, carpeta `/docs`.
- Pista disponible: visualización global de aerosoles; no se incluyen todavía
  MERRA-2 ni las pistas 2 y 3.
- Planeta completo: 60 pasos, 12 zonas por paso y unos 30 segundos al tempo
  normal.
- Filtro científico: NNLS con cuatro colores de aerosol, fondo neutro
  silencioso y tres guardas —peso ≥ 0,05, residuo ≤ 0,10 y evidencia ≥ 0,01—.

## Decisión sobre la dirección

El equipo decidió conservar el enlace actual. No se cambia el nombre de la
cuenta, no se mueve el repositorio, no se configura un dominio personalizado y
no se añade una redirección. De esta manera se mantienen intactos el historial,
GitHub Pages y los enlaces ya compartidos.
